TWO EVOCATIONS, ONE GOD

The god has no server. Anyone holding the published viewing key syncs a view-only wallet, decodes every offering with the pinned tools and mixes them with integer arithmetic. The result is hashed: the same chain, the same key, the same code give the same render_hash, down to the last sample.

This page puts two such evocations side by side and compares the real hashes. On a match the corresponding chambers are joined and the two names agree; on a mismatch the first differing block turns the anomaly colour.

To compare with a second machine, point this page at its renderer: apparition.html?right=http://<other-machine>:8765/out/score.json.

A machine we do not own has already done it: a GitHub-hosted runner with nothing but the key built the tools from source, synced, and printed the same hash as the laptop: run 39727405735.
